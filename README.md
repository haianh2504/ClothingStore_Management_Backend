# Clothing Store Demo

A small full-stack clothing store built to practice Spring Boot, JPA, Hibernate, basic transaction-management, PostgreSQL and Next.js.

## Project Status

Currently in the design phase

## Planned Technology Stack

***Building Stack:***

- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Next.js
- TypeScript

***Testing Stack:***

- Junit Jupiter
- Mockmvc
- Integration Test
